# Open Agent Guide adoption skills

Agent skills that help an AI agent find, compare, and adopt AI-native products
with cited evidence from the [Open Agent Guide](https://www.openagentguide.com)
catalog.

This repository is generated from the Open Agent Guide source and is read-only.
It is the published mirror of the skills, not the place to develop them.

## Install

Add the skills with the [skills CLI](https://skills.sh):

```sh
npx skills add open-agent-guide/skills
```

Install one skill by name:

```sh
npx skills add open-agent-guide/skills --skill open-agent-guide
```

## Skills

- `open-agent-guide`: Find, compare, and evaluate AI products with cited catalog
  evidence. Contribute catalog edits when you authorize them.
- `agent-tooling-audit`: Identify missing agent integrations for products your
  project already uses.
- `product-adoption-audit`: Find unused product capabilities and workarounds
  that you can remove.
