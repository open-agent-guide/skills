# Security policy

Report a security concern in these skills, or in Open Agent Guide, to
[support@openagentguide.com](mailto:support@openagentguide.com). Describe the
problem and the steps to reproduce it. Do not open a public issue for a
suspected vulnerability.

The skills read the public Open Agent Guide catalog over HTTPS and need no
account or credential for those reads. Do not place a token or other secret in a
skill, a configuration file, or a report.
